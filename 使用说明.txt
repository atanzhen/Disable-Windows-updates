一、这是什么
------------------------------------------------------------------------
彻底禁止 Windows 的自动更新、自动安装和自动重启。
电脑什么时候重启、什么时候关机，只有你自己说了算。

锁死之后：
  · Windows 不会自动检查、自动下载、自动安装更新；
  · 更新装完 / 蓝屏崩溃 / 计划任务 / 开机续装，任何路径都不会自己重启；
  · 系统里的更新计划任务全部禁用；
  · 部署一个守护任务，开机时 + 每 30 分钟巡检，设置被系统改回来自动修回来。

Windows 11    21H2 / 22H2 / 23H2 / 24H2 及后续
Windows 10    1507 / 1607 / 1709 / 1809 / 1909 / 2004 / 21H2 / 22H2 等全部版本
版本类型      家庭版、家庭单语言版、家庭中文版、专业版、专业工作站版、
              企业版、教育版、企业版 LTSC、IoT 企业版、Windows Server 2016+
架构          32 位 / 64 位 / ARM64

系统里不存在的服务或计划任务会自动跳过，不会报错，也不会影响系统。
程序启动时会检测系统版本，并在「系统环境」一栏显示是否受支持。


三、怎么用（三个主按钮 + 两个辅助按钮）
------------------------------------------------------------------------
  1. 双击「禁止自动重启工具.exe」，弹出授权窗口时点「是」。
     （程序已声明需要管理员权限；被杀毒软件拦下请选择允许）

  2. 点蓝色按钮「一键禁用更新和重启」，等上面五项状态全部变成绿色。
     此时主按钮会变成绿色的「已配置完成锁定」且不可再点，
     表示配置已完成，不需要再操作。之后完全不用管它，
     程序不需要常驻，也不用设置开机启动。

  3. 需要打补丁时：点「临时恢复更新」→ 设置里检查更新
     → 装完再点主按钮（此时又变回「一键禁用更新和重启」）重新锁定。

  4. 想彻底还原系统时：点「恢复配置」（会有二次确认），
     全部改动会被撤销，Windows 回到默认状态。

按钮说明（界面上每个按钮下面也写着）：

    一键禁用更新和重启      禁止自动更新与自动重启，并写入系统长期生效
                            （启用成功后显示为绿色的「已配置完成锁定」）

    临时恢复更新  只放开更新，自动重启仍禁止；装完补丁再点主按钮重新锁定
                  ※ 只有在已启用锁定时才能点，未启用时是灰色不可用的

    恢复配置      取消本程序的全部设置，恢复系统默认；更新与自动重启都会恢复
                  ※ 只有在已启用锁定时才能点，未启用时是灰色不可用的

    查看日志      守护任务只在修复被篡改项时写记录，空日志＝一切正常
    使用说明      软件内完整帮助

  为什么未启用时另外两个按钮是灰的：没启用锁定时系统本来就没有被改过，
  既没有"更新可恢复"，也没有"配置可还原"，所以不需要操作。


四、锁死成功后，打开设置会看到一个"错误"，这是正常的
------------------------------------------------------------------------
锁死之后打开  设置 → Windows 更新，会显示：

        "出现错误，请尝试稍后重新打开设置。"

这是预期现象，不是故障，也不是本程序出错了。
原因：Windows 更新引擎（Windows Update / 更新协调器 / 更新修复服务）
已经被停用，设置页读不到更新状态，所以显示这条提示。

它不会影响：
  · 电脑正常开关机、运行速度；
  · 安装 / 卸载软件，安装驱动；
  · 上网、办公、游戏、音视频；
  · 系统本身的任何功能。


五、为什么可以关掉、甚至删掉本软件
------------------------------------------------------------------------
所有设置都是直接写进系统的：
  · 注册表策略（HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate）
  · 服务启动方式（wuauserv / UsoSvc / WaaSMedicSvc）
  · 计划任务 NoAutoRestartGuard（SYSTEM 权限，开机 + 每 30 分钟）

守护脚本本身也复制到了 C:\ProgramData\NoAutoRestart\guard.ps1，
和 exe 所在位置无关。

所以：
  · 关掉本程序 —— 设置照样有效；
  · 删掉本程序 —— 设置照样有效，守护任务照样巡检；
  · 以后想改设置，重新下载本程序运行即可，它会自动识别当前状态。

本程序不常驻后台、没有开机自启项、不联网、不上传任何数据。


六、不影响什么（重点）
------------------------------------------------------------------------
以下这些本次完全没有改动，保持原样：

  · CBS / TrustedInstaller —— 启用或关闭 Windows 功能、安装系统组件正常；
  · Windows Installer (msiserver) —— 安装 .msi 软件正常；
  · BITS 后台传输服务 —— 下载行为正常；
  · 显卡、声卡、网卡、打印机等驱动安装；
  · 系统还原、系统服务、注册表其他部分。

唯一被改动的是「更新引擎」和「自动重启」，也就是本软件存在的意义。


七、需要你知道的副作用
------------------------------------------------------------------------
  1. Microsoft Store 应用自动更新、Defender 病毒库自动更新会一并停止。
     需要时点「临时恢复更新」，更新完再点「一键禁用更新和重启」。

  2. 系统不再自动获得安全补丁。建议每 1～2 个月手动恢复一次更新，
     装完补丁后自己点重启。

  3. 装更新期间，自动重启依然是禁止的，需要你手动重启才生效。

  4. 长时间不重启（比如一两个月）更新会堆积，重启时可能慢一点，属正常。


八、常见问题
------------------------------------------------------------------------
Q：点了「一键禁用更新和重启」提示执行失败？
A：多半是没有管理员权限。右键 exe → 选择「以管理员身份运行」。

Q：状态里「守护任务」显示"版本过期"？
A：说明系统里部署的是旧版本守护脚本，重新点一次「一键禁用更新和重启」即可更新。

Q：会不会被 Windows 改回去？
A：Windows 的更新修复服务、大版本升级确实会尝试恢复设置。
   守护任务每 30 分钟比对一次，被改回来自动改回去；
   「查看日志」能看到每一次修复记录，没有记录就说明一直正常。

Q：怎么确认它真的在跑？
A：点「查看日志」；或打开文件
   C:\ProgramData\NoAutoRestart\last-run.txt
   里面是最近一次巡检时间，每 30 分钟刷新一次。

Q：会不会影响我以后升级 Windows 大版本？
A：大版本升级需要更新服务，请先点「临时恢复更新」再升级，升级完再锁回去。


九、想彻底卸载怎么办
------------------------------------------------------------------------
  1. 打开本程序，直接点「恢复配置」→ 确认。
     它会自动完成：删除守护任务、恢复更新服务、删除本程序写入的注册表策略
     （只删本工具自己添加的项，系统其它注册表设置不动）、
     重新启用更新计划任务、恢复系统默认的自动重启设置、
     删除 C:\ProgramData\NoAutoRestart。
  2. 关掉程序，删除本文件夹（exe、说明、源码）即可，系统不留残余。

如果只想手动处理（不用本程序）：
  打开「任务计划程序」→ 任务计划程序库，找到 NoAutoRestartGuard 删除；
  再删除 C:\ProgramData\NoAutoRestart 文件夹。

注意：不做这两步的话，即使删了 exe，保护依然生效
——这正是「删了也不影响」的设计。
